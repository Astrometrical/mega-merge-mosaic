MegaMergeMosaic

Version 1.0.0 — Category: Mosaic

Big mosaics, no big deal.

Description

MegaMergeMosaic merges pre-aligned or plate-solved astro mosaic panels into a single seamless image. It analyzes the overlap regions between adjacent panels in narrow bands rather than processing full frames, matches gain and offset (background level) across panels in those overlaps, and composites the result with a seam-aware multiband blend so no panel edge is visible in the output.

Two families of input are supported:

  • Registered full-canvas panels — the output of PixInsight's MosaicByCoordinates process, where every panel already shares identical pixel dimensions and a common canvas.
  • Plate-solved panels — independently aligned panels that each carry their own astrometric solution; MegaMergeMosaic reprojects them onto a common frame before blending.

Panels can be supplied either as open views in the current workspace or as files on disk, and every panel must belong to the same mosaic.

Parameters

ParameterDescription
Target frames The panels to merge: either views of the current workspace, or files on disk. At least two panels are required, and all of them must come from the same mosaic — registered full-canvas panels (e.g. MosaicByCoordinates output) or plate-solved panels sharing overlapping sky coverage.
Session directory Directory used as the analysis cache (a *.mmm-session folder). All intermediate stage results are written here; re-running the process against the same session directory reuses any stage that has already completed, instead of recomputing it.
Input Auto (default) inspects the target frames: if they all share identical pixel dimensions, they are treated as registered full-canvas panels; otherwise the process falls back to plate-solved panels and reprojects them from their astrometric solutions. Aligned forces the registered full-canvas path. Solved forces reprojection from astrometric solutions, even if the frames happen to share dimensions.
Blend mode Feather blends overlaps with a simple weighted-average ramp. TwoBand feathers only the low-frequency component of the overlap and cuts the high-frequency component along a seam. Pyramid (default) performs a full multiband blend across several frequency bands for the best seam concealment and is the recommended setting for final output.
Feather Width, in pixels, of the blend ramp used at panel overlaps. Range 1–1024, default 256. Larger values spread the transition across more pixels, reducing the visibility of any residual mismatch at the cost of averaging over a wider region.
Surface fit order Polynomial order used when matching panel backgrounds (gain/offset) across overlaps. 0 fits a constant offset, 1 a plane, and 2 (default) a quadratic surface, allowing smoothly varying gradients across a panel to be matched.
Band rows Number of image rows processed per streaming band. Controls the granularity of the overlap-band analysis and the peak memory used while processing; default 256. Smaller values reduce peak memory at the cost of more processing steps.
Cross-panel defect veto When enabled (default), defects visible in only one of the overlapping panels — such as satellite trails or cosmic-ray hits — are detected and excluded from the blend in favor of the unaffected panel(s).
Flatten background Optional global gradient removal applied to the final merged mosaic, order 1 or 2. Disabled by default. The central level of the image is preserved; only large-scale gradients are removed.

Usage

  • Add at least two target frames (views or files) from the same mosaic using the Add Views… or Add Files… controls.
  • Choose a session directory; this is required before the process can run.
  • Click Apply (or drag the instance icon onto a view) to start the merge. Progress for each stage is reported in the Process Console as it runs.
  • To cancel a running instance, use the Process Console's Pause/Abort button.
  • On completion, a new image window containing the merged mosaic is created; the source panels are left unmodified.
