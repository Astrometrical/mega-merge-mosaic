# Phase 1 POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `docs/DESIGN.md` before any task — it defines the architecture and verified input-data facts. Task specs here give exact interfaces, algorithms, and tests; implementers own function bodies.

**Goal:** Working CLI POC: `analyze → report → blend` producing a photometrically-matched, feather-blended mosaic FITS from MosaicByCoordinates panels, validated against a synthetic ground truth and the real 12-panel Orion set.

**Architecture:** Sparse/overlap-band processing over mmap'd full-canvas XISF frames; L8 (1/8-res) per-panel summaries drive overlap graph, photometric solve, and previews; blend streams row bands at full res. All artifacts persist in a session dir.

**Tech Stack:** Rust 2024 workspace (`mmm-core` lib + `mmm` CLI). rayon, memmap2, quick-xml, bytemuck, serde/serde_json, clap, tracing. PNG preview via `png` crate. No nalgebra — hand-rolled dense LU (N ≤ few hundred).

## Global Constraints

- Linear data end-to-end. Pixel covered ⟺ **all channels nonzero**.
- Never allocate dense full-canvas buffers; canvas is up to 70000×30000. Per-band or L8-res buffers only.
- All heavy loops rayon-parallel. Real-data targets: analyze 12 panels ≲ 60 s cold, full-res blend ≲ 120 s.
- Unit/integration tests must NOT touch `test_data/` (synthesize inputs). Real-data runs are manual smoke tests.
- Every task ends: `cargo test` green, `cargo clippy --all-targets` clean, commit with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- L8 constant: `BLOCK = 8` (8×8 canvas pixels per summary cell). Grid dims: `w8 = ceil(w/8)`, `h8 = ceil(h/8)`; edge cells average over their actual pixel counts.

**Interfaces (Produces):**
```rust
// linalg.rs
/// Solve A x = b, A row-major n×n, LU with partial pivoting. Errors on singular.
pub fn solve_dense(a: &mut [f64], b: &mut [f64], n: usize) -> Result<Vec<f64>>;

// photometry.rs
pub struct EdgeFit { pub a: usize, pub b: usize, pub channel: u32,
    pub gain: f64, pub offset: f64,      // I_b ≈ gain·I_a + offset
    pub n: u64, pub rms: f64,            // post-clip residual RMS
    pub stats: [f64;6] }                 // n,Sx,Sy,Sxx,Syy,Sxy post-clip (x=panel a, y=panel b)
pub struct Photometry { pub edge_fits: Vec<EdgeFit>,
    pub gains: Vec<Vec<f64>>, pub offsets: Vec<Vec<f64>> } // [channel][panel]
pub fn solve(summaries: &[L8Summary], graph: &OverlapGraph) -> Result<Photometry>;
// + save/load JSON at analysis/photometry.json
```

**Algorithm:**
1. *Edge fit* (per edge, per channel, rayon over edges): collect pairs `(x,y)` from L8 cells inside `bbox8` where both `cov == 1.0`. 3 iterations: least-squares line via the six sums; then recompute residual σ and drop `|r| > 2.5σ`. Record final gain/offset/rms/stats.
2. *Global solve* (per channel): unknowns `z = [g_0,o_0,…,g_{N-1},o_{N-1}]`, minimize `Σ_e Σ_p ((g_i x + o_i) − (g_j y + o_j))²`. Normal-equation contributions per edge (x belongs to panel i=a, y to panel j=b), with `S=(n,Sx,Sy,Sxx,Syy,Sxy)`:
   - row g_i: `+Sxx·g_i +Sx·o_i −Sxy·g_j −Sx·o_j = 0`
   - row o_i: `+Sx·g_i +n·o_i −Sy·g_j −n·o_j = 0`
   - row g_j: `−Sxy·g_i −Sy·o_i +Syy·g_j +Sy·o_j = 0`
   - row o_j: `−Sx·g_i −n·o_i +Sy·g_j +n·o_j = 0`
   (Accumulate into A symmetric; RHS 0.) Gauge: for the largest-coverage panel in each connected component, overwrite its two rows with identity → `g=1, o=0`. Solve with `solve_dense`.
3. Normalize edge stats by `n` before assembling (divide all six by n) so large overlaps don't utterly dominate — weight each edge equally (POC choice; revisit).

- [ ] **Step 1:** Failing tests: (a) `solve_dense` on a known 3×3 system; (b) edge fit recovers `gain=2, offset=0.01` from synthetic pairs with 5% outliers injected; (c) global: 3 panels in a chain with known per-panel (g,o) applied to a common truth → recovered `g,o` within 1e-6 of inverting the applied transforms (ref panel fixed).

**Blend algorithm:** output bbox = union of panel bboxes. For each row band (rayon over bands): zero accum planes `wv[ch][band]`, `w[band]`. For each panel whose bbox intersects the band: mmap rows (full res) or L8 rows (downsample=8); for each pixel: covered? (all ch nonzero) → `d_px = 8·bilinear(dist_map, x/8, y/8)`; `wgt = max(min(d_px/feather,1), 1e-4)`; accumulate `wgt·(g_c·v + o_c)` per channel and `wgt` once. After panels: out = wv/w where w>0 else 0. Distance maps computed once per panel up front (Task 2 fn) and held (L8-res, small). For `downsample=8`, same flow over summary means (cov==1 cells only), output geometry (w8,h8).

Truth image: smooth 2-D gradient background (plane + low-freq sine), plus
`n_stars` Gaussian PSF stars (σ 1–3 px, amplitudes log-spaced, xorshift RNG from
seed — no external rand dep), plus Gaussian noise (Box-Muller from xorshift).
Panels: grid cells expanded by overlap, cut from truth, per-panel `v·g + o`
applied **to nonzero region only**, zero elsewhere, written full-canvas.
